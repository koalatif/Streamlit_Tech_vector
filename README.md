# Comparateur de Techniques de Vectorisation de Textes

Application **Streamlit** permettant de comparer plusieurs méthodes de vectorisation de textes (BoW, TF-IDF, Word2Vec, BERT) appliquées à des articles par rapport à un mot-clé.

## Fonctionnalités
- Chargement d’articles depuis un fichier CSV ou via scraping (optionnel)
- Nettoyage et prétraitement automatique du texte
- Comparaison de plusieurs méthodes de vectorisation :
  - Bag of Words (BoW)
  - TF-IDF
  - Word2Vec (si installé)
  - BERT (si installé)
-  Visualisation des scores sous forme de graphiques
